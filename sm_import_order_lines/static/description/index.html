Import Sale Order Lines from Excel/CSV

Save time and eliminate manual entry errors. Add hundreds of sale order lines to your quotes instantly with a single file upload.

Step-by-Step Visual Walkthrough

1

Access the Import Wizard

Navigate to any Sales Order form view. Click on the Actions cog icon and select Import Lines.

2

Configure Upload Options

Select your matching key, toggle header settings, and upload your CSV or Microsoft Excel file.

3

Format Your Source File

Keep your columns clean: Product Identifier in column A, Quantity in column B, Price in column C (optional), and Description in column D (optional).

4

Lines Imported & Calculated

All items are instantly populated, prices and taxes mapped, and totals recalculated automatically.
